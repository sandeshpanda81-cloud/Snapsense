# Submission Checklist

Before submitting the Snapdragon AI Lab Build & Present Challenge:

[ ] Confirm you own an eligible Snapdragon-powered HP PC.
[ ] Test the prototype on the target machine.
[ ] Verify which AI components actually run locally.
[ ] If using Qualcomm AI Hub models, document the exact model/version.
[ ] Record real performance measurements.
[ ] Capture 4–6 screenshots of the working application.
[ ] Record a short demo video if the submission form allows/requires it.
[ ] Prepare the proposal in English.
[ ] Explain technical implementation.
[ ] Explain the use case and innovation.
[ ] Explain deployment and accessibility.
[ ] Include architecture diagram.
[ ] Do not claim NPU acceleration without measurement.
[ ] Confirm the idea/code is your own work or properly licensed.
[ ] Double-check every submission field before final submission because the challenge rules state a submitted entry cannot be changed.
